# ISO 20022 in Kuntur

| Message | Direction | Endpoint | Purpose |
|---|---|---|---|
| `pain.001.001.09` CustomerCreditTransferInitiation | in | `POST /api/v1/payments/pain001` | Corporate bulk payments (payroll, suppliers) |
| `pain.002.001.10` CustomerPaymentStatusReport | out | response of the above (`Accept: application/xml` or JSON) | Per-transaction status with reason code |
| `pacs.008.001.08` FIToFICustomerCreditTransfer | out | `GET /api/v1/transfers/{id}/pacs008` | Interbank representation of a transfer |
| `camt.053.001.08` BankToCustomerStatement | out | `GET /api/v1/accounts/{id}/statements/camt053?from&to` | Account statement with opening/closing balances |

## Status codes used in pain.002
- `ACSC`: settled (booked on the ledger)
- `ACCP`: accepted, settlement in progress
- `PDNG`: pending four-eyes approval or risk review
- `RJCT`: rejected, with `StsRsnInf/Rsn/Cd`

Group status: `ACSC` if all settled, `RJCT` if all rejected, `PART` if some were rejected, `ACCP` otherwise.

## Reason codes
| Code | Meaning | Raised when |
|---|---|---|
| AC01 | IncorrectAccountNumber | Check digits fail or the account does not exist in this institution |
| AC04 | ClosedAccountNumber | Source or destination is closed |
| AC06 | BlockedAccount | Source account is frozen |
| AM02 | NotAllowedAmount | Daily limit exceeded |
| AM03 | NotAllowedCurrency | Currency differs from the account currency |
| AM04 | InsufficientFunds | Balance would go negative |
| DUPL | DuplicatePayment | `MsgId` already processed |
| FRAD | FraudulentOrigin | Declined by the risk engine or blocked by compliance |
| FF01 | InvalidFileFormat | Malformed or unsafe XML, `NbOfTxs`/`CtrlSum` mismatch |

## Identifiers
- **EndToEndId** comes from the pain.001 (or is generated) and travels to pacs.008 and camt.053.
- **UETR** is a UUID v4 assigned at intake, unique per transfer.
- **Account identifiers** use the IBAN structure (ISO 13616) with MOD 97-10 check digits; the institution code is
  the bank identifier. Ecuador does not use IBAN, so the structure is reused for its error-detection properties.
- **BIC** (ISO 9362) per institution, used in agent blocks.

A ready-to-edit example lives in [samples/pain001-sample.xml](samples/pain001-sample.xml); the web app can also
generate one prefilled with your own accounts.
